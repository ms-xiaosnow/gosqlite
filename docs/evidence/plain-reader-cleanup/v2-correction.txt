V1 independent source review found a public classification blocker: Rows.fail, Schema and plaintext import appended cleanup errors after an existing public *sqlite.Error. errors.As could therefore expose CodeBusy even when a later pending cleanup token also matched ErrPoisoned.
V2 uses wrapCleanup to classify the complete joined error through an outer wrap whenever cleanup is nonnil. Nil cleanup preserves the original result. The production helper is used by Schema/import defers and actual Rows.fail. Descriptor-free tests preserve BUSY and pending/poison causes and assert that the first public Error has CodeIOErr; actual Rows.fail runs with a memory-only release callback.
V1 remains immutable. This correction does not change native ownership algorithms, persisted formats, public structs or function types. The final V2 selection was rerun under normal, race, official intact probe, build/vet and compile-only Darwin/Windows checks.
Independent V2 rereview is required before integration.
