Reviewed 2026-10-10 UTC. Review is source inspection plus explicitly selected
ordinary tests, not a full external audit or durability qualification.

  bindings/scans, defaults, statement/transaction rollback and normal reopen.

Independent read-only reviewer checked strict decoding, representation identity,
NULL/zero-width split, precedence, exact ranking/ties, quotas, lazy query values,
ANN boundaries, snapshot use and truthful candidate recall disclosure.

Findings resolved before freeze:
1. Existing missing-column default paths used write canonicalization. For an
   external ALTER-added BIT(3) DEFAULT '001', official SQLite exposes INTEGER1
   on old records. Canonicalizing that to GSB guessed lost width. The new
   missingColumnValue helper applies ordinary BIT affinity while leaving dense
   behavior unchanged; only referenced typed values then reject. The ordinary
   oracle regression covers numeric rejection and canonical BLOB defaults.
2. A driver test's DESC ranking did not prove prior-statement/partial-row
   rollback. A direct in-transaction ids>=7 query now requires exactly row7,
   proving row8 is absent and row7 remains before transaction rollback.
