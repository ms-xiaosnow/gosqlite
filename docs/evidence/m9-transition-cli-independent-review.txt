Reviewed contracts
------------------
- Dispatch: explicit pgembedding transition is handled before the local-import
  fallback. Unknown --apply/--resume/--input flags cannot switch this handler to
  an import/apply path. Required catalog/options paths, duplicate flags, unknown
  flags and unexpected positional arguments fail before output publication.
- Input decoding: at most 64 KiB + one sentinel byte is read for options; larger
  input fails. Existing strictJSON rejects duplicate keys, unknown/exact-case
  fields, invalid UTF-8/NUL/Unicode escapes, wrong scalar kinds, trailing values,
  required null values, token excess and excessive nesting. Bounds are 8192
  tokens and depth 8. GenerateTransition retains responsibility for numeric,
  method, version, object-identity and other semantic checks.
- Required fields are explicit: every non-omitempty JSON field must be present,
  including zero/empty inapplicable options and lists/probes for HNSW mappings.
  The initially incomplete test fixtures were corrected by the owner; the
  decoder contract was not weakened. The supplied options.json is complete.
- Reads/output: the handler reads local catalog/options, calls only the offline
  generator/renderer, and fully renders the JSON envelope into a memory buffer
  before creating any requested report. Source catalog has its established
  16 MiB bound. Generated artifact content has the existing 8 MiB aggregate cap;
  bounded JSON escaping/envelope overhead is additional, not silently claimed
  to fit that same artifact-byte cap.
- No database/SQL execution: there is no database open/exec, DSN, network,
  subprocess or apply API on this dispatch path. The report is a JSON envelope
  of named text artifacts; core comment/read-only safety remains unchanged.
- Report preservation: optional report creation uses O_CREATE|O_EXCL, mode 0600.
  Existing files are refused rather than truncated/reused. This is an ordinary
  trusted local artifact workflow, not hostile ancestor-path/namespace-race
  protection. No namespace or symlink race was induced or certified.
- Context: an already-canceled context is checked before source opens; generation
  checks context and the handler checks again after rendering/before output.
  Ordinary synchronous local reads/writes are not an interruptible publication
  protocol. No claim is made that cancellation racing a final write prevents
  every possible output artifact.
- Errors: both source files are closed; read/decode and close errors are joined.
  Report write and close errors are joined; stdout/status writer errors return
  to the caller. A write/close failure may leave a partial report, and a later
  status-output failure may occur after the report is already written. No
  atomic publication, fsync durability, rollback cleanup or overwrite retry is
  implemented. These limits were reported to the owner for the CLI guide.
