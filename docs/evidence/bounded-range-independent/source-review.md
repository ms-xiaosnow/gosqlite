# Independent bounded cursor source review

Review baseline: ad73b8d6425cd86d1c15caccb0f858048df63ef9. All 837 tracked files in the initial owner tree matched baseline Git blobs; implementation is additive. Existing Cursor, IndexCursor, IndexRangeCursor, their layouts, table/index parsers, equality APIs, ordinary equality planning, and relational JOIN preallocation code are not edited.

The index range performs binary search at each page and records the exact ancestor child/record step for forward or reverse continuation. Interior index records are emitted; table interior rowids remain inclusive separator maxima only. Inclusive full-key hits can start at an interior record without visiting the preceding/following child, and exact terminal keys end without visiting adjacent subtrees. Prefix-bound cut comparison distinguishes before/after an entire suffix group, including bounds of different lengths. Signed endpoints are compared directly without increment/decrement at int64 extrema. Independent 3-/4-way tree properties cover multiple interior separators and leaf transitions.

The existing storage comparator is reused and agrees with the pinned public SQLite source in sqlite-src-3540000/src/vdbeaux.c sqlite3IntFloatCompare/sqlite3MemCompare. Independent expected ordering uses exact big.Rat arithmetic, separate type-class logic and bytes.Compare; it does not call production key/prefix/cut comparison helpers. It covers NULL/NaN, infinities, signed zero and smallest subnormal, values on both sides of 2^53 and int64 endpoints, BINARY TEXT including NUL, empty/nonempty BLOB, composite prefixes and signed trailing rowid distinctions. Descriptor-free trees are built from these independently ordered records. Read-only fixture and tagged CLI coverage supply overflow and 512/4096/65536-page checks.

New index descent reuses existing read-page/overflow ownership machinery. Binary probes and traversal decoded keys check strict inherited separator bounds; emitted keys check global directional monotonicity. Visited-page caps, repeated ownership, overflow arithmetic, actual page length, depth and visited-leaf depth remain active. Only visited/probed data are validated, so this is not a whole-file integrity scan. Pure-memory parser regressions cover malformed cell arrays and parent-bound contradictions; existing parser/ownership suites cover additional synthetic structures. Native physical failure branches were inspected only; no native fault, tamper or crash execution was used.

Cumulative budgets admit PageReader calls, parser buffers, record decode/payload and search comparisons. Every addition is bounded by remaining positive int64 credit before increment; field counts, page/usable sizes and uint16 cell counts bound multiplication. Stats.PageReads includes repeated overflow probes. Returned records are caller-owned; terminal EOF/error/cancellation releases traversal state and preserves stats. Reader lifetime remains borrowed. Source inspection verifies read errors propagate unchanged, but failed native operations are not exercised in this review.

Initial review found and retained a failing pure callback regression: BeforePage forwarded a nil hook result without rechecking cancellation, so parsing could allocate after the hook canceled context. A second retained regression demonstrates that two 5,000-byte endpoint BLOBs initially bypassed a 6,000-unit Work cap and read a page. Initial documentation disclosed endpoint copies as a separate finite cap, but the revised contract admits both copies before either allocation. Final qualification must verify the v2 fixes on immutable bytes, including post-hook context checks and checked endpoint-copy Work admission. The initial CLI test was also env-gated but untagged; final qualification requires the explicit oracle build tag and a separate bounded-oracle selection.

Bounded cursors are a low-level prerequisite only. No SQL inequality planning, ORDER BY elimination, covering reads, DESC/mixed-direction indexes, custom collations or WITHOUT ROWID claim is established. Work combines logical operations and admitted bytes; it is not wall-time, a physical-I/O count, or a complete heap limit. Physical-fault durability, non-Linux native runtime, and full database compatibility remain outside this review.

Final v2 qualification is now complete: all five reviewer suites pass, both admission regressions are repaired, explicit tagged CLI isolation is verified, and post-run owner/compiled-source/owned hashes all match.
