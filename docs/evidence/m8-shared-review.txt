Reviewed implementation:
- encstore shared root codec, selection ownership, capture/authority/publication,
  lifecycle/writer/capture OFD ranges, resource/retention/ID-ledger accounting.

- sqlite transaction integration and encryption verification/copy entry points.

Findings raised to implementation owner and disposition:
1. Candidate root decoding and PublishWAL ref cloning preceded a combined
   retained-selection/metadata preflight; refresh decoded metadata twice.
   Owner added bounded old-graph + twelve-root-extent + persistent-ledger
   admission before allocation and extracted openWALSelection to use one parse.
   Reviewed correction; normal quota regression preserves the old selection,
   master and authority and releases newly acquired byte1/byte2 ownership.
2. Shared current-authority cutover omitted the stable lock and pinned namespace
   rechecks that legacy Check retained. Owner added checkOwner before cutover
   and after publication. Verified in source only; no hostile mutation executed.
3. Checkpoint observed-header refresh was absent in an earlier source view.
   Current session code refreshes selectedHeader after successful checkpoint;
   the new regression proves idle A checkpoints B's latest grown head and
   returns current A.Info geometry. No failing runtime regression is claimed:
   first executable regression ran against the updated code.
4. Embedded selection migration left one existing Store{wal: ...} test literal.
   Owner corrected it to initialize selection explicitly.

Reviewed invariants:
- Layout3 is explicit; authenticated protocol byte and canonical reserves are
  checked. Old layout codecs are not widened. Root tokens cover exact complete
  authenticated root bytes, not just page-one counters/head content.
- Shared root capture closes the supersedable descriptor, releases the bounded
  byte2 capture gate before provider/KDF or full-graph work, and retains bounded
  authenticated bytes. Selected immutable names/extents/link checks and per-page
  authentication remain in force across normal root replacement.
- Independent connections own independent masters/OFDs. Writer-first admission
  precedes root refresh; expected-token promotion preserves an exposed snapshot.
  Ordinary contention/stale/quota/cancel/no-op paths retain correct ownership.
- Byte0 lifecycle is shared after creation/upgrade; byte1 serializes writers;
  byte2 gates capture/cutover. Globally quiescent rekey uses nonblocking atomic
  lifecycle conversion. CreateFrom owns exclusive lifecycle through return/close.
- Validation, physical verification, copy output and geometry use one retained
  selection through encryptedSnapshotView. It does not reenter Session.mu.
- Checkpoint selects latest authority before its no-segment decision. Old readers
  remain valid through commits and checkpoints. Fresh operations observe growth.
- Publication uncertainty and ownership poison take precedence over BUSY in
  pager and sqlite error mapping; these branches were reviewed in source, not
  induced through native failures. Memory-only composition checks are included.
- No externally anchored fresh-head guarantee, historical-key revocation, GC,
  cross-process global issuance count or process-global resource cap is claimed.

The copy regression publishes and checkpoints from B inside A's validation
callback before A starts output; both archive and plaintext copies retain A's
old selected data/geometry. Correct-key archive restore creates a shared target.
A separate concurrent history reads A's pinned pages while a goroutine performs
12 normal B commits and checkpoints, then verifies old and refreshed selections.
Quota refusal uses valid unchanged physical graphs and configured descriptor
limits. Invalid authority/layout/epoch/error-state cases are entirely memory-only.

Not executed: wrong-key/tampered/corrupt/missing-selected disk fixtures; namespace
replacement/retarget/race injection; actual native I/O/lock/unmap failure injection;
crash/kill/process-exit/hot recovery; failed Sync/short-write/disk-full/permission
faults; interrupted publication/rekey. Manual suites and aggregate tests were not
run. Initial new test compile corrections (Rows.Values and FileInfo fields) were
test API mistakes, corrected before the successful final named suite below.
