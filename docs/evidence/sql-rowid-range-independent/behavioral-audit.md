# Selected behavioral audit

The reviewer read `goal.md`, `docs/sql-rowid-ranges.md`, the owner handoff/audit, the bounded-cursor independent report, and selected source/tests/helpers before executing the selected suites. A successful `go run ./internal/testscope` precedes every test, race, oracle, build, and vet invocation in the recorded logs. This guard is supplementary, not a substitute for this audit.

- Owner `TestRowIDRange*`, `TestDriverRowIDRange*`, `TestStreamingMemoryCancellationAndClosure`, and `TestConnectorAndContext` perform ordinary SQL, streaming, named prepared binds, normal transaction rollback/BUSY, shared reader snapshots, context cancellation, close/reopen, and checkpoint. Pure-memory rational/budget probes read an existing intact fixture into owned bytes and do not tamper with its files.
- `TestOrdinaryIndex*` and their fixture helpers use ordinary correct-key native databases, schema/index creation, insert/update/delete, ordinary rollback/reopen/checkpoint, scalar residual errors, concurrency, normal extension-index checking, and logical PageReader counts. The selected ANN/IVF fixture builders issue ordinary SQL and public index creation. No manual fault/recovery helper is invoked.
- Reviewer `TestReviewRowIDRangeIndependentIntersections` uses ordinary native SQL over 191 rowids and an independent exact-rational/storage-class reference. `TestReviewRowIDRangeOrderAdmissionAndTies` compares ordinary SQL with genuine `NOT INDEXED` scans. They perform no physical mutation.
- Reviewer whole-planner tests copy the existing intact `page512.db` fixture into an owned byte slice, use its unchanged header/pages, and count logical PageReader calls through the complete SQL planner. Quotas are deliberate normal cursor resource limits on descriptor-free readers; cancellation is context cancellation. There is no injected native read/lock/close/unmap/Sync failure. Work=1 permits one page read before refusing page-parser allocation, which is recorded without claiming a zero-page result.
- Reviewer deferred-snapshot tests retain ordinary shared snapshots before the first Next while another connection normally commits, then test false/empty predicates, cancellation before traversal, ordinary DB/Rows close, and checkpoint.
- Owner and reviewer tagged oracle tests invoke only the explicitly pinned SQLite 3.54.0 CLI with normal EOF/process completion and read-only queries on intact native-created databases. They use no forced termination or CommandContext. The reviewer hashes each database before/after its comparison batch. The corrected parameter probe uses actual shell `.parameter` bindings. `integrity_check` is an ordinary read-only query.
- The baseline-gap probe creates a fresh ordinary database in each selected tree and demonstrates existing semantic differences. It does not modify any source baseline or physical database bytes directly.
- Builds and vet inspect/compile source; they do not run the repository's broad check script. Race instrumentation is the only use of `CGO_ENABLED=1`; production build is `CGO_ENABLED=0`.

No physical tamper/corruption/wrong-key/missing-file, namespace mutation, crash/kill/process-exit/hot-recovery, native I/O or lock/unmap/close/Sync/shortwrite/diskfull/permissions fault, interrupted publication, or rekey experiment was executed. No production CGO or external SQL path was introduced. The native root source was not edited, staged, committed, uploaded, or pushed. Review probes exist only in dedicated sibling copies; main-checkout writes are confined to this evidence directory.
