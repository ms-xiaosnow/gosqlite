# Dense-vector mathematical and codec contract

extension/vector is independently written pure Go. Its immutable Vector holds1..16,000 finite float32 components; zero Go Vector is invalid, not NULL. The public pgvector v0.8.7 tag is pinned to f37c13f68b57d2c3472b2214fbcff699d6d34876. Published fixtures are retained with hashes and license; PostgreSQL/pgvector was not executed.

New copies validated []float32; Values returns a copy. Parse/ParseDims accept bounded bracketed ASCII decimals with exponents and round directly to float32. Nonfinite/overflow, hex, underscores, quoted values and Unicode whitespace reject. Underflow to signed zero is accepted. Input is capped at1MiB and each numeric token at128 bytes. String emits shortest float32-round-tripping Go decimals; PostgreSQL formatting thresholds may differ.

L2Distance, L1Distance, CosineDistance and NegativeInnerProduct implement the four dense metrics. InnerProduct is the positive dot product; Norm is L2 norm. All arithmetic widens before operations and uses float64 Neumaier compensation. This intentionally differs from upstream float32/FMA-dependent rounding/overflow, so semantic compatibility is not bitwise metric equivalence. Finite float32 extrema/subnormals remain finite in this implementation. Cosine on any zero norm returns ErrZeroNorm; exact search aborts for an eligible zero-norm candidate rather than silently omitting it.

TopK/Scan rank exact distance ASC,signed rowid ASC, reject duplicate rowids/nonfinite custom metric results, skip explicit NULL rows and apply optional business filtering before scoring. Default SearchLimits are100,000 visited rows,10,000 results and2^27 charged components. All visited rows, including NULL/filtered rows, count against the candidate budget. No partial result survives errors/cancellation. Metric callbacks are trusted caller code. This pure package owns no ANN graph, IVF lists or database persistence; the sqlite integration supplies the documented database plans.

Vector implements driver.Valuer with versioned binary []byte. NullVector implements Scanner/Valuer: nil means SQL NULL, string means bounded text, []byte means strictly binary, never guessed text. Scan errors preserve the previous receiver; decoded vectors own their storage. The adapter alone is not VECTOR(n) column enforcement; sqlite now enforces declared dimensions.

Binary v1 is exactly12+4×dimensions bytes: magic GSV\x00, version1, component-format1 (IEEE754 binary32), byte-order1 (big-endian), zero flags, big-endian uint32 dimension, then big-endian float32 bit patterns. Signed zeros/subnormals round-trip exactly. Unknown version/flags/order, bad length/dimensions, extra bytes and nonfinite values reject before an unbounded allocation. There is no checksum/authentication; this is neither PostgreSQL wire/binary COPY nor an encrypted format.

Tests include selected30 published parse and31 metric examples, independent exact-rational/high-precision references, extremes, codec/immutability/adapters, bounded ranking and memory-only fuzz. Evidence is recorded in progress.md and evidence/m5-vector-prerequisite.txt. M6 now integrates database SQL/type enforcement, ordinary persisted read/write/reopen tests and exact KNN plans; see vector.md. Physical recovery, native-platform, independent legal/security and long-soak gates remain separate and unverified.
